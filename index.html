Coach (online)

A smarter, faster coach for when you're online, from a free LLM behind your own Cloudflare Worker. The Worker holds the API key — only your question leaves this phone, never your numbers. When you're offline, or the remote is down, the rule engine answers automatically. Free, no card.

Advanced · Worker URL and your own key

The rule engine answers every command first; open questions go to the online coach while it’s available. The coach runs on a free LLM behind your own Cloudflare Worker (it holds the API key — only your question leaves this phone, never your numbers), or on your own key below.

Bring your own key (direct)

No Worker needed — the coach calls the provider straight from this phone. The key is stored only on this device and sent only to that provider. Groq allows browser calls (recommended); for providers that block the browser, use the Worker URL above instead.

Backup

Your numbers live on this phone. Exports never leave it unless you share the file. CSV holds the ledger only.

What goes in the JSON

Import restores only what the file holds; the rest stays as it is.

Sync (your own GitHub gist)

Move your numbers to another phone through a PRIVATE gist — the data is encrypted on this phone (AES-GCM, key from your passphrase) before it ever leaves; GitHub only ever sees ciphertext. Push uploads, pull downloads + merges (per record, newest wins — nothing is silently overwritten). You need a GitHub account + a gist token (fine-grained, "Gists: read & write").
